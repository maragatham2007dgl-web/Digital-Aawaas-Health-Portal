# Aawaas Digital Health Portal

A simple frontend-only version of the Digital Aawaas Health Record project.

## Technology
- HTML
- CSS
- JavaScript
- Font Awesome CDN
- QRCode.js CDN
- Browser localStorage

## No backend required
This project does NOT use:
- Java
- Spring Boot
- Maven
- MySQL
- MongoDB
- Node.js

## How to run

1. Extract the ZIP file.
2. Open the `aawaas-digital-health` folder in VS Code.
3. Install the VS Code extension **Live Server** if you do not already have it.
4. Open `index.html`.
5. Right-click `index.html`.
6. Select **Open with Live Server**.

The browser will open the project.

## Features

- Aawaas Digital Health Portal design
- Blue header like the supplied screenshot
- English / Malayalam / Hindi / Bengali / Tamil language selector
- Online status
- SDG 3, SDG 8 and SDG 10 cards
- Migrant worker registration form
- Patient health records table
- Search records
- Edit patient
- Delete patient
- QR health card
- Print QR card
- Export records as JSON
- Responsive mobile design
- Browser localStorage

## Important

Because there is no backend/database, records are saved only in the browser where the project is opened.

Clearing the browser's site data can remove the saved records.
